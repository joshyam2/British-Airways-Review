# British-Airways-Review

## Description
This repository contains the Tableau workbook and csv files for my British Airways Reviews dashboard. The interactive dashboard contains a responsive ribbon of reviews at the top, filters to adjust for various ticket types, and graphs to further visualize the data. The project highlights my ability to tell a comprehensive story as I adjust the format, color, tooltip information, and font size to provide a clear, easy to understand breakdown of the data. 

## Key Features
- **Average Reviews:** Provides responsive responsive averages of a given ticket based on the selected features from the filters tab or graphs
- **Filters Tab:** Provides a selection of filters that can select which metric is to be measured, the ticket type, month, traveller type, seat type, aircraft type, and which continent the ticket was bought for.
- **Graphs:** This section provide a line graph, map, and bar graphs of the selected ticket types. The graphs display the results from the filters but they can also serve as their own filters, causing the other graphs to shape around them.
